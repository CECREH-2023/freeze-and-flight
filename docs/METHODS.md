# Methods and interpretation

How did recorded residential transaction composition and prices change within the inherited flood footprint?

Descriptive deed-record analysis for 2015–2022. Improvement-value categories are not independently verified building conditions; inherited inundation metadata and later parcel linkage limit interpretation.

## Analytical sequence

Classify eligible recorded transactions, link them to the inherited flood footprint and comparison bands, construct annual composition and real-price outcomes, and estimate descriptive changes with wild-cluster inference and leave-out checks. The default bootstrap count remains 9,999.

## Sources and scope

Nebraska deed records; county assessor/parcel records; inherited inundation and FEMA SFHA geometries; BLS CPI.

All ten focused scientific tests pass. Full estimation needs the records listed in data/INPUTS.json, including the classifier reference corpus and stored production predictions. Serialized original BERT weights are not locally available; the code documents stored-prediction matching and the distilled classifier. No new classification or estimation was run in this package.
